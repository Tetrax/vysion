# Références Directory

This directory contains reference files needed for report generation.

## Files Included

All required reference files have been copied from the original legacy application:

### Images (PNG format)
- `sns-security-logo1.png` - Main logo used in Excel reports
- `sns-security-logo.png` - Alternative logo variant
- `sns-security-logo-actions.png` - Logo for action sheets in Excel reports  
- `sns-security-logo-account.png` - Logo for account sheets in Excel reports
- `ISDB.png` - ISDB illustration for Word reports
- `CTI.png` - CTI illustration for Word reports
- `cluster.png` - Cluster illustration for Word reports
- `Security_profiles.png` - Security profiles illustration for Word reports

### Additional Images
- `Image-entete.jpg` - Header image
- `image_fond.jpg` - Background image
- `shield.ico` - Icon file

### Documents (DOCX format)
- `generique.docx` - Template document for Word report generation

## Notes

- All files have been copied from the original `.venv/Références/` directory
- The application will create this directory automatically if it doesn't exist
- Missing files will cause report generation to fail with helpful error messages
